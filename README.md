# Tarun Karmakar, portfolio

Personal portfolio site: programme delivery work, impact numbers, career timeline, and coaching.

- `index.html` is the portfolio.
- `coaching.html` describes life and career coaching.

Plain HTML, CSS and JavaScript. No build step.

## Publish with GitHub Pages

Name this repository `tarun03k.github.io`, then in Settings > Pages choose "Deploy from a branch", branch `main`, folder `/ (root)`. The site appears at https://tarun03k.github.io.
