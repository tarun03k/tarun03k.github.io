CASE STUDY 1 · AI AND GENAI

Bringing GenAI into the software lifecycle

A large engineering organisation needed AI coding tools it could trust on security, privacy and cost.

Context
Roll out a GenAI coding assistant and agentic tooling to thousands of developers without weakening engineering controls.
My accountability
OKRs, roadmap and executive reporting for a team of about 15. Guardrails and evaluation criteria for every AI release, capacity allocation, and vendor and commercial negotiations.
Key decisions
  • Host the assistant on-prem.
  • Release in three phases, each with training, adoption governance and readiness checks.
  • Gate AI releases on security, privacy and output quality, using Snyk, SonarQube and Sonatype Firewall.
  • Add LiteLLM and OpenCode, and an in-house agent harness, for multi-model access and cost-aware routing.
Execution
Phased rollout to IntelliJ and VS Code users, then agents, MCP integrations, AI pull-request review, Golden Repos and Skills for non-development teams. AI agents took over RAID logs and status reporting.
95% adoption Realised 25% PR throughput Realised ~6 hrs saved per dev per week (survey) Realised 40% less reporting time Realised ~30% lower model cost Target

Technology decisions

Technology decisions I have driven

Six choices I helped make with engineering and architecture teams, and what each one achieved.

Multi-model orchestration and routing

Need
Reliable access to several AI models, with cloud spend under control.
Approach
LiteLLM and OpenCode, plus an in-house agent harness built for the engineering environment, routing each request automatically.
Result
Models stay available and reliable, and routing is designed to bring Azure cost down by about 30% (target).

Enterprise RAG and knowledge retrieval

Need
Answers from company knowledge, not from a model guessing.
Approach
DevBot on Azure Cognitive Services, using retrieval-augmented generation over a vector database.
Result
An internal chatbot grounded in enterprise knowledge, taken from concept to deployment.

AI coding assistant security controls

Need
Use AI in the codebase without exposing code or lowering quality.
Approach
On-prem hosting, with Snyk, SonarQube and Sonatype Firewall gates on every AI release.
Result
Rollout in three gated phases to 95% adoption.

Dynamic CI runner architecture

Need
Pipelines were waiting hours for static runners.
Approach
Auto-scaling runners on Red Hat OpenShift, proven in MVP, infrastructure work and Alpha and Beta trials before about 500 pipelines moved.
Result
Average job wait fell from 4 hours to 1, with fewer security incidents and less patching.

Software supply-chain governance

Need
Know what is in the code and block risky components early.
Approach
SBOM and software composition analysis with Flexera and Snyk, plus real-time scanning for malicious npm dependencies and licence approvals.
Result
Taken from proof of concept to MVP across 16K+ repositories.

Hardware and software integration for retail

Need
Real-time replenishment guidance on a device in a colleague's hand.
Approach
Wi-Fi, BLE, REST APIs, cloud services and MDM, released through trial, MVP and rollout gates.
Result
Trial results of 10% more colleague productivity and 25% more availability for operational tasks (trial).
